## Known weak points and caveats

- P1 has no upper separation bound while detection needs a fitted separation <= 1.5"; some counted recoveries (systems with literature separation > 1.5") are fitted on sub-structure at a separation different from the literature value.
- The calibration pool's real clean stars contain genuine faint companions (ratio ~20-40 at 0.7-0.8"), which set T* far above the synthetic-single level (AMENDMENTS A6). Synthetic singles never flag, so the pooled P4 rate is dominated by the 20,000 synthetics; the real held-out rate is the informative number.
- Injected and planted images use the same tile PSF as the detector (optimistic); no source photon noise is added; the PSF ignores colour and position dependence within a tile.
- P4b's chance-projection figure counts all MER sources to VIS 24.5, most far too faint for this detector; it is an upper bound, not a like-for-like expectation.
- P6 compares at the baseline's own operating point (false-claim rate ~29%), not at a science-grade false-claim rate.
- Blind set: sealed by `seal.py` in the same agent session that wrote the detector (code and T* committed first; key stored only under E:\claudestronomy-cache\sealed and not read before grading). A separate sealing session is a later hardening step.
- 40 tiles are ~0.5% of DR1; the parent sample is 705 (target 1,500) and the blind set 472 usable files (target 500).
- Nothing here establishes that any object is a lens (evidence gate at most G1, model-checked).
