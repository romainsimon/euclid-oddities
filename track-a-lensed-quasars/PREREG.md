# Probe 0 pre-registration: compact lensed quasars in Euclid DR1

Frozen: 2026-11-13, before any Euclid pixel was fetched. Parent specification: `businesses/claudestronomy/prototype-spec.md` in the CEO workspace (copied table below is verbatim). Any later change goes to `AMENDMENTS.md`, labelled planned fill-in or post hoc. This file is hashed into `PREREG.sha256` and committed before the first pixel request.

Catalogue-only orientation queries made before freezing (no pixels): `dr1.mosaic_product` schema and VIS row counts (14,064 rows, 10,990 distinct `tile_index`; purposes `DATA_RELEASE` 9,730 and `DATA_RELEASE_DEEP` 4,334), `dr1.mer_catalogue_wide_survey` schema, Heidelberg Gaia DR3 column lists, SIMBAD (Harvard mirror) counts of lens object types (`LeQ` = 188), and the Wayback CDX index of the Lemon lensed-quasar database.

## 1. Metrics and thresholds (copied verbatim from the spec)

| ID | Metric | PASS | FAIL | INCONCLUSIVE |
|---|---|---|---|---|
| P1 | Recovery of known lensed quasars with separation ≥ 0.3″ and faintest image VIS < 23 | ≥ 80% | < 80% with N_known ≥ 8 | N_known < 8: report the fraction and exact binomial interval, no verdict |
| P2 | Injection completeness, separation ≥ 0.4″, flux ratio ≤ 5, faint image VIS ≤ 22.5 | ≥ 90% | < 90% | none |
| P3 | Separation at which completeness for flux ratio ≤ 2 crosses 50% | ≤ 0.3″ | > 0.3″ | none |
| P4 | Noise false-alarm rate on held-out clean singles (synthetic and real, pooled) | ≤ 0.1% (T* was set for 0.05%) | > 0.1% | fewer than 10,000 held-out trials |
| P4b | Flag rate on all proper-motion stars (stellar binaries plus chance projections) | reported only | n/a | n/a |
| P5 | Blind set: recall on planted doubles within the P2 range, and false claims on unplanted cutouts | recall ≥ 85% and false-claim rate ≤ 3% | otherwise | none |
| P6 | Blind set: our recall minus the pixel-level baseline's recall, at the baseline's false-claim rate | > 0 with a 95% bootstrap interval excluding 0 | ≤ 0 | interval includes 0 |
| P6b | Known real objects: our recovery versus the MER-catalogue and Gaia-flag baselines | reported only | n/a | n/a |
| P7 | Re-run output hashes | identical | different | none |
| P8 | Every pixel and table used has a manifest row with a matching SHA-256 | 100% | below 100% | none |
| P9 | Cutout throughput | reported only (cutouts per second, bytes per cutout) | n/a | n/a |

Overall: the probe **passes** if P2, P4, P5, P7 and P8 pass and P1 is PASS or INCONCLUSIVE. P3 and P6 are reported; a P6 failure means the simpler baseline is used going forward, which is an acceptable outcome.

These numbers are design choices made before seeing any Euclid pixel. They are not derived from data.

## 3. Operational definitions (frozen with the table)

### 3.1 Tiles
- Tile table: `dr1.mosaic_product`, `instrument_name='VIS'`, `product_type='DpdMerBksMosaic'`. One row per `tile_index`: prefer `purpose='DATA_RELEASE'`, else `DATA_RELEASE_DEEP`; ties broken by latest `creation_date`.
- Candidate tiles: distinct tiles named in (or containing positions of) the ECLIPSE object catalogue (Zenodo record 19654904). Sort tile ids ascending, then draw 40 without replacement with SEED_TILES. Add every tile containing a known lensed quasar (section 3.3).
- Development tiles: 2 further ECLIPSE tiles drawn with SEED_DEV from those not selected and containing no known lensed quasar. Detector and PSF development use only these tiles. No tuning on parent, calibration, held-out, injection, known-object or blind data.

### 3.2 Samples (Gaia DR3 through the Heidelberg mirror, positions inside the 40 random tiles, at least 15″ from the tile edge)
- "Single within 3″": no other Gaia DR3 source within 3″.
- Parent-eligible: `in_qso_candidates = true` and single within 3″.
- Blind pool drawn **first**: 500 parent-eligible sources, SEED_SAMPLES. Parent sample: the remaining parent-eligible sources, subsampled to 1,500 with SEED_SAMPLES if more. Shortfall is reported, not filled from other tiles.
- Stars: (`parallax_over_error` > 5 or proper-motion significance sqrt((pmra/pmra_error)² + (pmdec/pmdec_error)²) > 5, correlations ignored), 18 < G < 20.5, single within 3″. Subsampled to 4,000 with SEED_SAMPLES if more.
- Clean singles: stars with `ruwe` < 1.2 and `ipd_frac_multi_peak` = 0. Split 50/50 with SEED_SPLIT into calibration and held-out halves.
- Secondary purity cut (reported only, does not change any verdict): parent or blind sources with `classprob_dsc_combmod_quasar` > 0.5 and `in_galaxy_candidates = false`.

### 3.3 Known objects
- Sources, in order: the Lemon lensed-quasar database (archived copy if the live site fails), SIMBAD object type `LeQ` (any working mirror), tables of arXiv:2206.07714. Images are de-duplicated into systems (positions within 5″ merged).
- Kept if a `dr1.mer_catalogue_wide_survey` row lies within 2″ and the position falls in a DR1 VIS tile. N_known = number of kept systems meeting the P1 eligibility below.
- P1 eligibility uses literature values, never our own fit: maximum image separation ≥ 0.3″ from the literature list; faintest-image VIS < 23 proxied by, in order, the literature faint-image magnitude, the Gaia DR3 G of the faintest Gaia component within (separation + 0.5″), or the faintest MER `flux_vis_psf` magnitude within (separation/2 + 0.5″). Objects without a separation are excluded and listed.
- Reported-only variants: P1 restricted to 0.3″ ≤ separation ≤ 1.5″ (the detection window), and the ECLIPSE grade A systems with a Gaia quasar candidate within 3″ (second labelled set).

### 3.4 Cutouts and PSF
- 120 × 120 VIS pixels (12″ × 12″) centred on the catalogue position, from the background-subtracted mosaic. An official IRSA cutout route is preferred if it exists and returns identical pixels to range-read assembly on a test tile; otherwise single-range requests per row.
- PSF: per tile, sigma-clipped median stack of 20 bright isolated Gaia stars (18 < G < 19.5, no other Gaia source within 5″, `ruwe` < 1.4, outside the samples above), normalised to unit sum. Interpolation and oversampling choices are detector-development choices made on the dev tiles and frozen by commit hash before T* is computed.

### 3.5 Detector and statistic
- Fit box: 41 × 41 pixels centred on the brightest pixel within 1″ of the cutout centre (proper-motion stars have moved since Gaia's epoch).
- Background noise σ_b: 1.4826 × MAD of cutout pixels more than 3″ from the centre, after 3σ clipping.
- Pixel variance: σ_b² + (0.03 × M₁)², where M₁ is the best single-PSF model (clipped at 0). The same weights are used for both fits.
- Models: one PSF plus constant (4 parameters) and two PSFs plus constant (7 parameters). T = (χ²₁ − χ²₂) / 3.
- Detection: T > T* and fitted separation in [0.15″, 1.5″].

### 3.6 T* rule (planned fill-in)
- Calibration pool: 20,000 synthetic singles (SEED_SYN_CAL) plus the calibration half of clean singles.
- With N_cal sources and k = floor(0.0005 × N_cal), T* is the (k+1)-th largest T among calibration sources with fitted separation in the window (T* = 0 if fewer than k+1 such sources). The number goes to `AMENDMENTS.md` as a planned fill-in, hashed, and is not changed.

### 3.7 Synthetic singles
- Sky patches: per tile, 40 candidate positions drawn uniformly (SEED_SKY) ≥ 15″ from the edge; a patch is accepted if no pixel in the central 41 × 41 of the 3 × 3 box-smoothed image exceeds 3σ_b. First 20 accepted per tile; even-index to the calibration set, odd-index to the fresh set (fewer if not enough pass, reported).
- Source: the tile PSF, total VIS magnitude uniform in [19, 22.5], sub-pixel offset uniform in ±0.5 px. No source photon noise is added (stated limitation). Synthetic and real held-out rates are reported separately as well as pooled.
- VIS magnitude: −2.5 log₁₀(flux) + `zero_point` of the mosaic row (PSF normalised to unit sum; no aperture correction).

### 3.8 Injection (step 10)
- Hosts: parent quasars with no detection. Image B: tile PSF copy at the given separation from the host's fitted single position, random angle, flux = host flux / ratio. Faint image VIS = host magnitude + 2.5 log₁₀(ratio).
- Grid: separation {0.15, 0.2, 0.3, 0.4, 0.6, 1.0, 1.5}″ × ratio {1, 2, 5, 10} × 200 draws (SEED_INJ). Half of each cell also gets a deflector.
- Deflector: Sérsic n = 4, R_e uniform [0.2″, 0.6″], axis ratio uniform [0.6, 1], random position angle, total VIS uniform [20.5, 22.5], centred on the line from the bright to the faint image at fraction ratio / (1 + ratio) of the separation (SIS geometry), convolved with the tile PSF.
- P2 subset: separation ≥ 0.4″, ratio ≤ 5, faint image VIS ≤ 22.5. P3: completeness versus separation for ratio ∈ {1, 2} pooled, linearly interpolated; reported as ≤ 0.15″ if already ≥ 50% there, > 1.5″ if never.

### 3.9 Blind set (step 11)
- 500 blind-pool cutouts. `seal.py` draws a fresh seed, chooses 100 (20%) to plant among hosts with VIS ≤ 22.5, and plants a double: separation uniform [0.4″, 1.5″], ratio log-uniform in [1, min(5, 10^((22.5 − m_host)/2.5))], random angle, half with a deflector as in 3.8. Every plant is inside the P2 range.
- All 500 files are rewritten identically (same format, neutral shuffled names, tile id and zero point only). Key (mapping, planted flags, parameters, seed) goes only to `E:\claudestronomy-cache\sealed\`. Nothing about the key goes to stdout, logs or the in-tree manifest.
- Detector, T* fill-in, baseline parameters, `grade.py` and `seal.py` are committed (hash recorded) before the key exists.
- P5: recall = detected planted / planted; false-claim rate = detected unplanted / unplanted.

### 3.10 Pixel-level baseline (step 12)
- `photutils`: image convolved with a 5 × 5 Gaussian kernel of FWHM 2 px; `detect_sources` with threshold 1.5σ_b and `npixels` = 5; `deblend_sources` with default parameters. A baseline claim: at least two segments with centroids within 2″ of the cutout centre and some pair separated by 0.15″–1.5″.
- P6: let F_b be the baseline false-claim rate on unplanted cutouts. Our operating threshold T_b is the smallest T threshold whose false-claim rate is ≤ F_b. Difference = our recall at T_b − baseline recall. 95% interval from 2,000 bootstrap resamples of cutouts, stratified planted / unplanted, recomputing T_b each time (SEED_BOOT). PASS if the 2.5th percentile > 0; FAIL if the point estimate ≤ 0; otherwise INCONCLUSIVE.
- Catalogue baselines (P6b, known objects only): (a) two MER entries within 1.5″ of each other, both within 2″ of the position; (b) Gaia DR3 `ipd_frac_multi_peak` ≥ 10 or two Gaia sources within 2″.

### 3.11 False positives, P4b
- P4: flags among (20,000 fresh synthetic singles + held-out clean singles). INCONCLUSIVE if fewer than 10,000 trials.
- P4b: flag rate on all proper-motion stars, beside the chance-projection rate 1 − exp(−π ρ (1.5² − 0.15²)), ρ = density of MER sources with VIS PSF magnitude < 24.5 in a 3′ cone at the tile centre.

### 3.12 Intervals, determinism, provenance
- Rates are reported with exact (Clopper–Pearson) 95% intervals.
- P7: steps 7–13 re-run from the cache; SHA-256 of every CSV in `tables/` must match. Tables contain no timestamps or throughput numbers and are sorted by id.
- P8: every cached file used has a manifest row with matching SHA-256; every request (TAP included) goes through `manifest.py`.
- Stop rules: shrink the number of tiles before relaxing any rule; disk caps 5 GB on E:, 1 GB on D:.
